# OpenSSL 4.0 Compatibility Assessment for OpenSSL Native Layer

Date: 2026-03-31
Target: OpenSSL 4.0 compatibility check across `src/main/native/openssl`

## Summary of Findings
- Identified deprecated OpenSSL 3.0 APIs that will be removed or made opaque in OpenSSL 4.0.
- Low-level legacy APIs (DSA_*, RSA_*, EC_KEY_*, d2i_/i2d_ for raw key structs, EVP_PKEY_get1_*, HMAC_CTX_*) must transition to provider-based EVP_PKEY APIs (OSSL_PARAM, EVP_PKEY_fromdata, EVP_PKEY_todata, EVP_PKEY_encrypt/decrypt/sign/verify, EVP_MAC).
- Build files require configuration updates for OpenSSL 4.0 library names/paths.
